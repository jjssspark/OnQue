# ADR-0005 · 채팅 답변과 할 일 추출을 한 번의 호출로 합친다

- 상태: 채택
- 날짜: 2026-08-17
- 출처: `docs/specs/2026-08-17-ai-call-budget-design.md`

## 맥락

채팅 메시지 하나를 처리하는 데 `generate_bot_reply` 1건 + `extract_chat_actions` 1건,
총 2건을 썼다. 하루 한도가 20건이므로 메시지 10개면 그날이 끝난다.

`/문서` 명령도 마찬가지로 2건을 쓰고 있었다. 이미 받아온 `structured["category"]`를
버리고 `classify_document_category`를 무조건 다시 불렀다.

## 결정

두 호출을 `chat_reply_with_actions` 하나로 합친다. 스키마는 기존 추출 스키마에
`reply: STRING`을 더한 형태다.

`/문서`는 이미 받아온 값을 쓰고 없을 때만 분류를 부르는 폴백 형태로 바꾼다.

## 이유

새로 만든 방식이 아니다. 비서 패널(`answer_assistant`)은 이미 한 번의 호출로 답변과
액션 제안을 함께 받고 있었다. 채팅방 경로만 같은 일을 두 번 나눠 부르고 있었다.

업로드 경로도 이미 폴백 형태로 고쳐져 있었고 `/문서` 경로에만 빠져 있었다. 같은 수정이
두 경로 중 한 곳에만 적용된 상태였다.

## 결과

메시지당 2건에서 1건이 됐다. 같은 한도 안에서 실질 처리 용량이 두 배가 됐다.

품질 저하 여부는 실측으로 확인했다. 4턴 대화에서 잡담 오추출이 없었고 상대 날짜
변환도 정확했다.
