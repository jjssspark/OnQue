# ADR-0004 · 장부 차감은 별도 세션에서 즉시 커밋한다

- 상태: 채택
- 날짜: 2026-08-17
- 출처: `docs/specs/2026-08-17-ai-call-budget-design.md`

## 맥락

채팅 메시지 저장은 쓰기 트랜잭션 한가운데에서 일어난다. 그 안에서 장부를 깎으면
어떻게 되는가.

기존 스윕 예산 차감 코드는 같은 세션을 썼지만 문제가 없었다. 약속 목록 조회(읽기 전용)
중에 불렸기 때문이다.

## 결정

장부 차감은 요청 트랜잭션과 분리된 세션에서 하고 곧바로 커밋한다.

## 이유

같은 세션에서 커밋하면 아직 완성되지 않은 쓰기까지 함께 커밋된다. 읽기 경로에서
무해했던 방식을 쓰기 경로에 그대로 옮길 수 없다.

DB가 Postgres(Neon)라 별도 커넥션 동시 쓰기에 락 문제가 없다.

## 결과

라우터는 세션을 넘기지 않는다. `user_claimer()`가 부를 때마다 스스로 세션을 열고
닫는다. 게이트웨이 계층은 DB를 모른 채 호출 가능 객체만 받는다.
