# ADR-0007 · 할 일 중복 제거 가드를 넣지 않는다

- 상태: 채택 (조건부 재검토)
- 날짜: 2026-08-18
- 출처: `docs/ai-call-budget-followups.md`

## 맥락

ADR-0005로 답변과 추출을 합치면서 추출이 참고하는 범위가 "새 메시지 1개"에서
"최근 20개"로 넓어졌다. 프롬프트로 다시 좁혔지만, 이는 완화이지 차단이 아니다.

`_apply_extracted_actions`에는 중복 제거가 없다. 받은 대로 `db.add(Todo(...))` 한다.
모델이 프롬프트를 안 지키면 상한 없이 매 턴 한 행씩 쌓인다.

## 결정

4턴 연속 대화 실측에서 중복이 생기지 않는 것을 확인하고, 가드를 넣지 않는다.

## 이유

안 생기는 것을 확인했는데 방어 코드를 넣으면 실행되지 않는 코드가 는다.

## 한계 — 이 결정의 근거는 코드가 아니다

4턴은 모델이 프롬프트를 지킨 사례 하나이지, 지킬 수밖에 없다는 증명이 아니다.
아래 중 하나라도 바뀌면 이 항목은 다시 열린다.

- 추출 프롬프트의 중복 방지 지시를 고칠 때
- 모델을 바꾸거나 버전을 올릴 때
- 참고하는 대화 범위를 넓힐 때
- 한 방에서 5턴 넘는 대화가 실제로 생길 때 (이번 실측은 4턴까지만 봤다)

재검토 시 판정 기준의 출발점은 "같은 `content`와 `due_date`의 미완료 행이 이미 있으면
추가하지 않는다"이다.
