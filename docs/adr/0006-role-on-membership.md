# ADR-0006 · 역할을 전역 사용자 속성에서 그룹 멤버십으로 옮긴다

- 상태: 채택
- 날짜: 2026-08-06
- 출처: `docs/specs/2026-08-06-group-scoped-roles-design.md`

## 맥락

`routers/auth.py:55`가 `role="admin" if is_first_user else "member"`였다.
DB 전체에서 가장 먼저 가입한 한 명만 admin이 된다.

그룹 생성은 admin만 가능하므로, 두 번째로 가입한 사람은 팀을 만들 수도 초대를 받을
수도 없었다.

운영 DB 실측(2026-08-06)에서 실제로 그 상태가 확인됐다. 한 사용자가 어느 그룹에도
속해 있지 않았다.

## 결정

역할을 `users` 테이블에서 `group_memberships`로 옮긴다. 사람마다 그룹별로 다른 역할을
가진다.

## 이유

역할은 사람의 속성이 아니라 사람과 그룹 사이의 관계다. 전역에 두면 한 사람이 여러
그룹에 속할 때 표현할 방법이 없다.

## 결과

그룹 생성과 생성자 멤버십 삽입을 같은 트랜잭션에 둔다. 나누면 멤버가 없는 고아 그룹이
남는다.

마이그레이션은 컬럼을 방금 추가한 경우에만 기존 `created_by`를 admin으로 승격시킨다.
재실행 시 수동 변경을 덮어쓰지 않기 위해서다.
